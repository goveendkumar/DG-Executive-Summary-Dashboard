 DG Executive Summary & Profitability Dashboard

 Project Overview
This project presents an interactive Excel dashboard designed to analyze sales performance, revenue, and profitability.

 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Interactive Filters

 Key Features
- Revenue and Gross Profit KPIs
- Profit Margin Analysis
- Monthly Revenue and Profit Trends
- Top 5 Countries by Revenue
- Revenue Share by Channel
- Region-Wise Revenue Comparison
- Interactive Dashboard Filters

 Objective
The objective is to transform raw sales data into meaningful business insights and support data-driven decision-making.

 Skills Demonstrated
Excel, Data Analysis, Dashboard Design, Data Visualization, and Business Intelligence.
